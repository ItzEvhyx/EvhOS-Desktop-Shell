# Snapshot lineage

`EvhOS-Desktop-Shell` is the portable, current desktop snapshot for this configuration.

It began from the tested installer, restoration tooling, documentation, and AGPL-3.0 licensing of [`ItzEvhyx/EvhOS-Shell`](https://github.com/ItzEvhyx/EvhOS-Shell) at commit `316157a485d1d837998fe03a141dcef308d77de6`. This repository then captures the active CachyOS/Hyprland/Serpantinum configuration, including the local HyprMod profile and desktop state.

The two repositories are intentionally separate: the earlier repository remains a reference checkpoint, while this repository is the one to clone and update for reproducing this desktop.
